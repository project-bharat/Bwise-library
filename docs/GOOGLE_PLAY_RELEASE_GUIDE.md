This is a repository-specific preparation checklist, not legal advice or a promise of approval. Google Play policies and Console workflows change. Recheck the official sources and the requirements shown in the developer account before each submission; the account owner makes final declarations and submits releases.

## Before preparing a release

- [ ] Confirm the developer account is in good standing and complete any identity or organization verification requested by Play Console.
- [ ] Confirm the app ID, app name, version code, version name, signing key, and release track.
- [ ] Review the current Play target API requirement and set the generated Android project accordingly. Do not rely on an old generated project or an old policy deadline.
- [ ] Configure secure release signing outside source control. Restrict key access and retain a protected backup.
- [ ] Build a signed Android App Bundle (`.aab`) and test that exact release variant. Archive the source revision, bundle, build logs, and test evidence.
- [ ] Inspect the merged release manifest and dependency inventory. Confirm every permission, SDK, network request, and background behavior is necessary and disclosed.
- [ ] Publish a public HTTPS privacy policy and link it where Play requires. Ensure it accurately describes local library storage, contact data, notifications, file export/sharing, and any network services actually present.
- [ ] Complete Data safety, app access, content rating, target audience, ads, and other Play Console declarations from the final app behavior and SDK inventory.
- [ ] Prepare accurate listing text, screenshots, icon, support contact, and release notes.
- [ ] Test fresh install, upgrade, backup/restore, offline use, permissions, notifications, and device compatibility. Review Play's pre-launch report.
- [ ] Review any closed-testing or production-access requirements displayed for this specific developer account.

The app's Android setup script currently adds contacts and notification permissions. Verify the final merged manifest and ensure the privacy policy and Play declarations reflect the actual permissions and data use.

## Submission boundary

This repository guide does not authorize access to the developer account, changing Play Console settings, uploading an artifact, or publishing a release. The account owner should review the final build and declarations and perform Console actions.
